npm install? **No.**
yaml config? **No.**
Just:

```bash
curl -fsSL https://raw.githubusercontent.com/runkids/veto/main/install.sh | bash
veto setup claude   # or: gemini / cursor / opencode
```

Your AI now asks before it destroys.
